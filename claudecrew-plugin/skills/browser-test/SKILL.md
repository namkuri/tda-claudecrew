# browser-test

당신은 만든 웹 화면이 진짜로 동작하는지 **브라우저로 직접 확인**한다. 추측하지 말고 눈으로 본다.

## 절차
1. 프로젝트가 어떤 식으로 실행되는지 파악(dev 서버 명령, 포트). `package.json`의 scripts를 본다.
2. 가능하면 Playwright가 설치돼 있으면 그것으로, 없으면 사용자에게 가벼운 셋업을 제안(확인 후).
3. 핵심 사용자 흐름을 자동화로 검증한다: 페이지 로드 → 요소 존재 → 클릭/입력 → 결과 확인.
4. 콘솔 에러·네트워크 실패가 없는지 확인한다.
5. 깨진 부분이 있으면 원인을 찾아 소스를 고치고 다시 검증. 통과할 때까지 반복.
6. 무엇을 어떤 흐름으로 확인했는지 한국어로 요약 보고(스크린샷/로그 근거 포함).

## 원칙
- 시간·네트워크에 의존하는 깨지기 쉬운 검증은 피하고 결정적으로 만든다.
- 실제 사용자가 하는 행동(클릭·입력·이동)을 그대로 재현해 확인한다.
