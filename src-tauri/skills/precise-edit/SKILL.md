# precise-edit — 의미 기반 정밀 편집

큰 코드베이스에서 무차별 텍스트 치환은 위험하다. **심볼/구조 수준**으로 정확히 고친다.

## 정밀 편집(MCP)이 켜져 있으면
- `.mcp.json`에 연결된 LSP/시맨틱 도구(serena 등)를 사용해 심볼을 찾고, 참조를 추적하고, 정의 단위로 편집한다.
- 함수/클래스/변수의 **모든 참조**를 확인한 뒤 바꾼다(이름 변경·시그니처 변경 시 누락 방지).

## 도구가 없으면(폴백)
- grep으로 정의↔사용을 대조하고, 좁고 고유한 매칭으로만 치환한다.
- 한 번에 한 심볼씩, 변경 후 빌드/타입체크로 회귀를 확인한다.

## 원칙
- 최소 diff: 의도한 곳만 바꾼다. 포맷·무관한 줄은 건드리지 않는다.
- 이름/시그니처 변경은 호출부·테스트·문서까지 함께 갱신한다.
- 동적 참조(문자열 기반 호출, 리플렉션)를 놓치지 않는다. 확신 없으면 표시하고 남긴다.
